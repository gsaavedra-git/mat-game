🌊 Ondas e interferencia

¿Qué está pasando?

Cada fuente emite ondas circulares. Donde dos crestas se encuentran, las amplitudes se suman (interferencia constructiva, brillante). Donde una cresta encuentra un valle, se cancelan (interferencia destructiva, oscuro). Arrastra las fuentes para ver cómo cambia el patrón.

📚 La ecuación de la onda

Cada fuente emite una onda circular descrita por:

y(r, t) = A·cos(k·r − ω·t)

Donde:

  • r = distancia desde la fuente
  • k = 2π/λ = número de onda (λ es la longitud de onda)
  • ω = frecuencia angular (qué tan rápido oscila)
  • A = amplitud (decae con la distancia)

➕ Principio de superposición

Cuando varias ondas coinciden en un punto, sus amplitudes se suman:

ytotal = y1 + y2 + … + yn

Interferencia constructiva (zonas brillantes): dos crestas se encuentran y se refuerzan. Ocurre cuando la diferencia de caminos es múltiplo de λ.

Δr = n·λ

Interferencia destructiva (zonas oscuras): cresta y valle se cancelan. Ocurre con diferencia de medio λ.

Δr = (n + ½)·λ

💡 Aplicaciones reales

Este fenómeno es la base de muchísima física:

  • Experimento de Young (doble rendija): demostró que la luz es una onda.
  • Holografía: usa interferencia para grabar imágenes 3D.
  • Auriculares con cancelación de ruido: generan ondas en oposición de fase.
  • Antenas direccionales: combinan múltiples emisores para concentrar la señal.
  • Mecánica cuántica: las partículas también interfieren consigo mismas.

Prueba a usar 1 fuente sola: solo ves ondas circulares concéntricas, sin patrón. La magia aparece con 2 o más.
